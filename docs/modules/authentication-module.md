# Authentication Module

## Location
`src/components/LOGINSIGNUP/`

## Files
1. **Login.jsx**:
   - Handles user email/password entry.
   - Includes links to Signup and Password Recovery (Coming Soon).
2. **Signup.jsx**:
   - Facilitates new user registration.
   - Collects user details and roles.

## Internal Logic
- **State Management**: Uses React's `useState` for form fields.
- **Form Submission**: Currently logs input to the console and navigates to the home page on "success".
- **Styling**: Shared authentication theme consistent with the project's branding.
