# Prerequisites

To run this project, you need the following tools installed on your local development machine:

## Tools
- **Node.js**: Recommended version 18.x or 20.x (LTS).
- **npm**: Usually comes bundled with Node.js. Alternatively, you can use **yarn** or **pnpm**.
- **Git**: For version control and cloning the repository.
- **Web Browser**: Modern browser (Chrome, Firefox, Safari, or Edge) with Redux/React DevTools (optional but recommended for development).

## Recommended IDE
- **Visual Studio Code (VS Code)**
  - Recommended Extensions:
    - ESLint
    - Tailwind CSS IntelliSense
    - ES7+ React/Redux/React-Native snippets
