# Installation Guide

Follow these steps to set up the project locally:

## 1. Clone the Repository
```bash
git clone https://github.com/your-username/cpccu-client.git
cd cpccu-client
```

## 2. Install Dependencies
Using npm:
```bash
npm install
```
Or using yarn:
```bash
yarn install
```

## 3. Verify Installation
Ensure that the `node_modules` folder is created and all dependencies from `package.json` are installed correctly.
