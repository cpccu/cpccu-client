# Technology Stack

## Core
- **React.js (18.2.0)**: UI Library.
- **Vite (7.0.5)**: Build tool and development server.
- **JavaScript (ES6+)**: Core programming language.

## Styling
- **Tailwind CSS (3.4.3)**: Utility-first CSS framework.
- **PostCSS / Autoprefixer**: CSS processing.
- **FontAwesome**: Icon library.
- **React Icons**: General-purpose icon set.

## Routing & Navigation
- **React Router DOM (6.23.0)**: Client-side routing.
- **React Scroll**: Smooth scrolling utilities.

## Utilities
- **clsx / tailwind-merge**: Conditional CSS class management.
- **date-fns**: Modern JavaScript date utility library.
- **Jodit React**: WYSIWYG editor for content management.
- **React Countup**: Animation for numerical data.

## Development Tools
- **ESLint**: Linter for identifying and fixing code patterns.
- **Prettier**: Code formatting (recommended).
- **Node.js**: Runtime environment for development.
