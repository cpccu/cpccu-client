# User Management

## Components
- **Profile Component**: `src/components/Layout/Profile.jsx` (Currently a placeholder for viewing user details).
- **Directory Components**:
  - `Committee.jsx`: Displays university leadership.
  - `Alumni.jsx`: Displays the alumni database.
  - `Member.jsx`: Displays general community members.

## User Roles (Concept)
- **General User**: Can view events, blogs, and public directories.
- **Authenticated Member**: Can participate in community-specific forums or pipelines.
- **Admin**: Future role for managing content and users.

## Data Source
User data is fetched from the following JSON files:
- `data/Committee.json`
- `data/Alumni.json`
- `data/Member.json`
