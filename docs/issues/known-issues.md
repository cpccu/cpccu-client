# Known Issues

This document tracks known bugs, limitations, and areas of improvement that are currently being addressed.

## Functional Issues
- **Form Persistence**: Authentication forms do not currently persist state after a page refresh.
- **Image Placeholders**: Some sections lack optimized image placeholders, leading to layout shifts during load.
- **Search Logic**: Search functionality in the directory modules is currently limited to client-side filtering of static JSON.

## UI/UX Issues
- **Mobile Navigation**: The mobile menu toggle occasionally fails to close after a navigation event.
- **Animations**: Certain scroll animations may feel sluggish on low-end mobile devices.

## Reporting Issues
If you encounter a bug that is not listed here, please open a New Issue on GitHub with the following details:
1. Steps to reproduce the bug.
2. Expected vs. actual behavior.
3. Screenshots or screen recordings (if applicable).
4. Browser and OS details.
