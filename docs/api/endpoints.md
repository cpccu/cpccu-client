# Internal Endpoints (Data Files)

## Featured Data Files

### 1. Upcoming Events
- **File**: `data/upcomingEvent.json`
- **Description**: Contains the list of events displayed on the home page and event sections.
- **Usage**: Imported by `EventLayout.jsx`.

### 2. Alumni Directory
- **File**: `data/Alumni.json`
- **Description**: List of university alumni with their details.
- **Usage**: Imported by `Alumni.jsx`.

### 3. Blog Posts
- **File**: `data/BlogPost.json`
- **Description**: All community blog articles and news updates.
- **Usage**: Imported by `Blog.jsx`.

### 4. Committee Members
- **File**: `data/Committee.json`
- **Description**: Details of current committee members and their roles.
- **Usage**: Imported by `Committee.jsx`.

### 5. Gallery
- **File**: `data/GalleryBodyCard.json`
- **Description**: Metadata for images and albums in the community gallery.
