# Core Services

## Utility Functions
Located in `src/lib/`:
- **cn.js**: The primary service for CSS class merging and concatenation.

## Shared Contexts
Located in `src/Context/`:
- **Scroll Providers**: Managing target-based scrolling across the application.
  - `BlogScrollProvider`
  - `ContactScrollProvider`
  - `OurMissionScrollProvider`
  - ... and others.

## Global Components
Located in `src/components/Global/`:
- **UpComingEventCard**: Reusable unit for event display.
- **GallaryCard**: Standardized card for gallery items.
- **NotFound**: Reusable 404 page component.
