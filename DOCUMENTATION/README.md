## Cross-repository links

CPCCU is split into two repositories. The **backend** is documented in the other repo:

- [cpccu-server docs index](https://github.com/cpccu/cpccu-server/blob/dev/docs/INDEX.md)
- [cpccu-server architecture](https://github.com/cpccu/cpccu-server/blob/dev/docs/ARCHITECTURE.md)
- [cpccu-server API reference](https://github.com/cpccu/cpccu-server/blob/dev/docs/API_REFERENCE.md)
- [cpccu-server environment variables (both repos)](https://github.com/cpccu/cpccu-server/blob/dev/docs/ENVIRONMENT.md)

**Division of responsibility:** this repo owns the UI, routing, state, and static content (`data/`). The backend owns the API, MongoDB, authentication enforcement, email, uploads, and the GitHub contributor write-back. Contributor data originates in `data/contributors.json` (this repo), is regenerated by the GitHub Action in `.github/workflows/`, and is edited through the backend's `/admin/contributors` endpoints.
