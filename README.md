# CPCCU Client

[![React](https://img.shields.io/badge/react-%2320232a.svg?style=for-the-badge&logo=react&logoColor=%2361DAFB)](https://reactjs.org/)
[![TailwindCSS](https://img.shields.io/badge/tailwindcss-%2338B2AC.svg?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)

CPCCU (Comilla Promod Chandro Community University) Client is a modern, high-performance web application designed for students, alumni, and committee members to connect and collaborate.

- **Content Docs**: [Google Docs](https://docs.google.com/document/d/1HLcmyFrLobvaKXmtZ88-6vrPee5g-6hVEDZag_Cm2to/edit)

## 🚀 Features
- **Community Directories**: Comprehensive lists of Alumni, Committee members, and more.
- **Event Management**: Track upcoming and recent community events.
- **Blog Platform**: Share stories, news, and updates.
- **Job Pipeline**: A dedicated section for career opportunities within the community.
- **Modern UI**: Built with Tailwind CSS for a premium, responsive experience.

## 🛠 Technology Stack
- **Core**: React 18, Vite
- **Styling**: Tailwind CSS, FontAwesome
- **Routing**: React Router 6
- **Data**: Static JSON (Architected for future REST API integration)

## 📦 Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/rahulroynipon/cpccu-client.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

## 🔨 Running the Project
- **Development**: `npm run dev`
- **Build**: `npm run build`
- **Preview**: `npm run preview`
